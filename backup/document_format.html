長いコンテンツ（スクロール確認用）

top

このページは、左側の項目リストから記事を選ぶと中央にコンテンツが切り替わり、右側のアウトラインから見出しへジャンプできるひな形です。

概要

ここは概要の説明です。本文を編集して自分のドキュメントに置き換えてください。Bootstrap のドキュメントページ（getbootstrap.com/docs）のように、左で章を選び、右でその章の中の節へ移動する操作を想定しています。

各カラムは独立にスクロールします。左の項目が多くても、中央の文章が長くても、右のアウトラインが長くても、必要なカラムだけに縦スクロールバーが自動で出ます。行数が収まる間はスクロールバーは表示されません。

使い方

左の項目リストから選ぶ

左側のリンクをクリックすると、中央の記事が差し替わります。選択中の項目は緑色でハイライトされます。

右のアウトラインから移動する

右側には、現在表示中の記事の h2 / h3 が自動で一覧表示されます。クリックすると中央のコンテンツだけが滑らかにスクロールして該当見出しが表示されます。中央をスクロールすると、現在位置に合わせた見出しがアウトライン側でハイライトされます（Scrollspy 相当）。

編集する場所

追加・削除・文面変更はこのファイルだけを編集すれば終わります。左ナビの <a class="doc-link" data-doc="..."> と、中央の <article class="doc-panel" data-doc="..."> の data-doc を同じ値で揃えてください。

<!-- 左ナビ -->
<a href="#my-topic" class="doc-link" data-doc="my-topic">新しい項目</a>

<!-- 中央記事 -->
<article class="doc-panel" data-doc="my-topic">
  <h1>新しい項目</h1>
  <h2 id="my-topic-1">見出し1</h2>
  <p>本文…</p>
  <h2 id="my-topic-2">見出し2</h2>
  <p>本文…</p>
</article>

item0

グリッドやコンテナなど、ページの骨格を作るための基本です。

コンテナ

.container は最大幅が決まった中央寄せの箱、.container-fluid は幅いっぱいの箱です。このひな形では 3カラム全体に container-fluid を使っています。

グリッドシステム

ブレイクポイント

画面幅に応じてカラム数を変えたい場合は col-md-* などを使います。狭い画面では左ナビとアウトラインが上下に回り込みます（このページの CSS の @media (max-width: 991.98px) 参照）。

Flex で 3カラムにする場合

このひな形の 3カラムは Bootstrap のグリッドではなく Flex（display: flex）で組んでいます。各カラムに overflow-y: auto を指定することで独立スクロールを実現しています。

独立スクロール

ページ全体を止めて各区画だけをスクロールさせるには、親の高さを calc(100vh - ヘッダー高さ) に固定し、子に overflow-y: auto と min-height: 0 を付けます。
